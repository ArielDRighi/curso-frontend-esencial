# 📚 Curso Completo de Java Spring Boot

## 🎯 Descripción

Curso integral de desarrollo backend con Java Spring Boot orientado a la construcción de APIs REST para ecommerce. Incluye desde fundamentos hasta temas avanzados como microservicios, seguridad, testing y DevOps.

## 🚀 Características

- **10 módulos completos** con 126-148 horas de contenido
- **Proyecto práctico**: API de ecommerce completa
- **Referencias técnicas**: 60+ recursos organizados por categorías
- **Prompts de IA**: Asistentes especializados para desarrollo y migración
- **Progreso persistente**: Seguimiento automático del avance
- **Interfaz responsive**: Adaptable a dispositivos móviles

## 📋 Contenido del Curso

### Módulos Principales

1. **Fundamentos de Java** (12-15 horas)
2. **Spring Boot Básico** (14-16 horas)
3. **Spring Data JPA** (13-15 horas)
4. **API REST Avanzadas** (12-14 horas)
5. **Spring Security** (15-17 horas)
6. **Testing** (10-12 horas)
7. **Microservicios** (18-20 horas)
8. **Mensajería** (12-14 horas)
9. **Performance y Cache** (10-12 horas)
10. **DevOps y Despliegue** (16-18 horas)

### Tecnologías Incluidas

- **Backend**: Java 17+, Spring Boot 3.x, Spring Data JPA, Spring Security
- **Base de Datos**: PostgreSQL, Redis Cache
- **Testing**: JUnit 5, TestContainers, Mockito
- **DevOps**: Docker, Kubernetes, CI/CD
- **Documentación**: Swagger/OpenAPI, Spring Boot Actuator

## 🏗️ Proyecto: API de Ecommerce

El curso incluye la construcción paso a paso de una API REST completa para ecommerce con:

- 👤 **Gestión de usuarios y autenticación JWT**
- 🛍️ **Catálogo de productos con categorías**
- 🛒 **Carrito de compras y gestión de sesiones**
- 💳 **Procesamiento de pagos e integración con gateways**
- 📦 **Gestión de inventario y stock**
- 📊 **Panel de administración y reportes**
- 🔍 **Búsqueda avanzada y filtros**
- 📱 **API REST documentada con Swagger**

## 🛠️ Instalación y Uso

1. **Clonar el repositorio**

   ```bash
   git clone [URL-del-repositorio]
   cd curso-java-web
   ```

2. **Abrir en navegador**

   ```
   Abrir index.html en cualquier navegador web moderno
   ```

3. **Comenzar el curso**
   - Navegar por las pestañas: Dashboard, Módulos, Referencias, etc.
   - Marcar completadas las lecciones para seguir el progreso
   - Utilizar los prompts de IA para asistencia
