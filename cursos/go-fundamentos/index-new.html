🛠️ Proyecto Integrador: API REST de Gestión de Tareas

📋 Descripción del Proyecto

Desarrollarás una API REST completa para gestión de tareas utilizando Go, PostgreSQL y las mejores prácticas de arquitectura backend.

🛠️ Tecnologías

  • • Go 1.21+ con Gin Framework
  • • PostgreSQL con GORM
  • • JWT para autenticación
  • • Docker para contenedores
  • • Testing con Go testing

🎯 Funcionalidades

  • • CRUD completo de tareas
  • • Sistema de usuarios y autenticación
  • • Filtros y búsqueda avanzada
  • • API RESTful con documentación
  • • Despliegue en producción
